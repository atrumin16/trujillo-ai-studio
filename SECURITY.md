| Version | Supported          |

---

## Reporting a Vulnerability

Security is a fundamental priority for Trujillo AI Studio. If you identify a security vulnerability, please report it privately:

- Email: alberto@trujillomingorance.com
- Subject: `[Security] Trujillo AI Studio Vulnerability`

Please provide:
- A detailed summary of the vulnerability
- Steps to reproduce or proof-of-concept payload
- Assessment of potential impact

We will respond to acknowledge receipt within 48 hours and work with you to remediate the issue prior to public disclosure.
